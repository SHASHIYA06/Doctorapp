   198→### Key Design Decisions
   199→- **Tenant Isolation:** All clinical endpoints filter by the first active tenant
   200→- **Zod Validation:** Every POST/PUT uses Zod schemas for input validation
   201→- **Audit Trail:** Clinically meaningful operations (create, update, sign, acknowledge, triage) create AuditEvent records
   202→- **Safety Checks:** Deterministic allergy checking, drug interaction lookup (Warfarin/Aspirin/Ibuprofen etc.), and red flag symptom pattern matching
   203→- **Care Plan Signing:** When a draft is signed, a SignedCarePlan record is automatically created
   204→- **AI Consent Gate:** AI-generated clinical drafts require an active AI_ASSISTED consent for the patient's modality
   205→- **Commerce-Clinical Boundary:** No commercial endpoints (Supplier/Product) exposed in clinical API routes
