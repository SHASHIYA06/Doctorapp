   235→   235→### Key Design Decisions
   236→   236→- **Tenant Isolation:** All clinical endpoints filter by the first active tenant
   237→   237→- **Zod Validation:** Every POST/PUT uses Zod schemas for input validation
   238→   238→- **Audit Trail:** Clinically meaningful operations (create, update, sign, acknowledge, triage) create AuditEvent records
   239→   239→- **Safety Checks:** Deterministic allergy checking, drug interaction lookup (Warfarin/Aspirin/Ibuprofen etc.), and red flag symptom pattern matching
   240→   240→- **Care Plan Signing:** When a draft is signed, a SignedCarePlan record is automatically created
   241→   241→- **AI Consent Gate:** AI-generated clinical drafts require an active AI_ASSISTED consent for the patient's modality
   242→   242→- **Commerce-Clinical Boundary:** No commercial endpoints (Supplier/Product) exposed in clinical API routes
